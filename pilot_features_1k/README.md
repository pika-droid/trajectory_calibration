# Pilot Features (FOR TESTING ONLY)

This directory contains synthetic mock multi-scale extraction checkpoints (100 samples each)
for both M3-LLaVA (scales: 1, 9, 36, 144, 576) and MQT-LLaVA (scales: 1, 9, 36, 144, 256).

**IMPORTANT**: These features are intended exclusively for fast offline CPU testing (`python scripts/run_mock.py` and `pytest`),
not for reporting scientific benchmark numbers.
